# Calculadora PY

## Como rodar

    python calculadora.py

## O que ela faz

    é uma calculadora que tem as opções de:
    adição, subtração, divisão, multiplicação, resto(fração) e potência
    podendo receber até 2 inputs de números para os cálculos

## Limitação conhecida

    quebra ao usar uma string

## Um bug que encontrei

    se receber uma string em qualquer input ele quebra
